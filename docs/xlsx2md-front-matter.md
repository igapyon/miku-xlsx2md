# xlsx2md Front Matter Contract

This document defines the YAML front matter emitted at the beginning of
Workbook-level combined Markdown generated by `miku-xlsx2md`.

The contract is intentionally small. It identifies the converted artifact and
records the conversion settings that materially affect the Markdown body.

## Scope

By default, this front matter applies to saved combined Markdown and to the
Markdown entry inside ZIP output. Export callers may set `frontMatter:
"exclude"` and the CLI may use `--front-matter exclude` to omit it.

It does not apply to internal per-sheet Markdown fragments returned by the
product core before export composition.

## Output Shape

Combined Markdown starts with YAML front matter by default, followed by the
Workbook heading and Sheet sections:

```markdown
---
title: "sales.xlsx"
type: converted
conversion:
  tool: miku-xlsx2md
  version: "1.3.0"
  output_mode: display
  formatting_mode: github
  table_detection_mode: balanced
  shape_details: exclude
---

# Book: sales.xlsx

## Sheet: Summary
```

## Field Contract

| Field | Shape | Meaning |
|---|---|---|
| `title` | string | Workbook file name used for conversion output. |
| `type` | string | Stable artifact type. Current value: `converted`. |
| `conversion` | object | Tool and option metadata for this conversion. |

## Conversion Object

`conversion` records the settings that materially affect generated Markdown:

| Field | Shape | Meaning |
|---|---|---|
| `tool` | string | Tool name. Current value: `miku-xlsx2md`. |
| `version` | string | `package.json` version used by the CLI or export caller. |
| `output_mode` | string | `display`, `raw`, or `both`. |
| `formatting_mode` | string | `plain` or `github`. |
| `table_detection_mode` | string | `balanced`, `border`, or `planner-aware`. |
| `shape_details` | string | `include` or `exclude`. |

## Agent Reading Guidance

AI agents may use front matter to identify a converted Workbook artifact and
which conversion settings were used.

Do not rely on front matter alone to reconstruct Workbook content. The
converted content lives in the Markdown body under `# Book: ...` and
`## Sheet: ...` sections. Detailed diagnostics may appear in summaries or
future sidecar artifacts rather than in front matter.
